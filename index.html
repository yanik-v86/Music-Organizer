Music Organizer

A powerful web-based music file manager with automatic tag reading, audio fingerprint identification, and smart file organization.

Python · FastAPI · Mutagen · AcoustID

Features

🎵 Automatic Tag Reading
📁 Smart File Organization
🔍 Audio Fingerprint Identification
🤖 AI-Powered Filename Analysis
🎨 Cover Art Extraction
📊 Batch Operations
🔔 Gotify Notifications
🌐 Modern Web Interface
⚡ Background Task Queue
🛠️ RESTful API

Supported Formats

MP3 FLAC M4A / AAC OGG WAV WMA OPUS

Quick Start

Install system dependencies 
$ sudo apt-get install python3-pip chromaprint-tools
Clone and set up 
music-organizer/$ python3 -m venv venv
music-organizer/$ source venv/bin/activate
music-organizer/$ pip install -r requirements.txt
Configure — edit config.yaml with your source directory, output path, and AcoustID API key.
Run the server 
$ uvicorn app.main:app --host 0.0.0.0 --port 8181

API Endpoints

Method Endpoint Description
GET/api/filesList files with filters
GET/api/files/{id}Get file details
GET/api/files/{id}/tagsGet file tags
PUT/api/files/{id}/tagsUpdate tags
POST/api/files/{id}/identifyIdentify track via AcoustID
POST/api/files/{id}/analyze-llmAnalyze filename with LLM
POST/api/files/moveMove selected files
POST/api/scanScan source directory
GET/api/tasksList background tasks
GET/api/configGet configuration
PUT/api/configUpdate configuration
